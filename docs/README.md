## 一句话现状（v1）

**技术上可行（有条件）、境内不可上架发行、且未经真机验证。** 三件事必须分开看：

1. **技术可行** —— 官方 `vpnExtension` 是面向三方应用的公开能力（只需 `INTERNET`），门禁就是用户授权弹窗；已有真机先例。
2. **境内不可上架** —— 法规（《暂行规定》第六/十四条）+ 备案制度 + 平台明文不收录 VPN 类应用；所有先例都走侧载。
3. **最硬的工程阻塞在 Go** —— `GOOS=android` 借道已被尸检到 `socklen_t` 标准库冲突（无编译开关可解）+ cgo TLS 墙。

另有两个**必须由人拍板**的前置条件：**许可决策**（MIT+Xray(MPL) vs GPL+sing-box）与**发行形态决策**。
详见 [`00-技术路线可行性.md`](00-技术路线可行性.md)。
