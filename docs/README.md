## 一句话现状（v2，2026-10-12）

**技术可行已由真机验证（端到端跑通）、境内不可上架发行、且尚未成为可用产品。** 三件事分开看：

1. **技术可行 —— 🧪 已验证，不再是推断**：官方 `vpnExtension` 是面向三方应用的公开能力
   （只需 `INTERNET`），门禁就是用户授权弹窗。2026-10-12 在 HUAWEI `TYR-AL00`（API 24）上
   跑通了 **编译 → 自动签名 → 安装 → 授权 → 建 vNIC → 内核 → 端到端出网** 全链路，
   并回答了**两个长期未确定项**：`libcore.so` 能在 OHOS 上运行、
   `hev-socks5-tunnel` 能接管 OHOS 的 vNIC fd。
2. **境内不可上架** —— 法规（《暂行规定》第六/十四条）+ 备案制度 + 平台明文不收录 VPN 类应用；所有先例都走侧载。
3. ~~**最硬的工程阻塞在 Go**~~ → **已解除**：项目自建了一份支持 `c-shared` 的 OHOS Go 工具链
   （见 `04`~`08`），产物 `libcore.so`（34.5 MB）已在真机上 `dlopen` 并正常工作。

**必须由人拍板**的前置条件还剩一项：**长期工具链是否接受自建 fork**（供应链决策）。
许可按"仅自用"已定为 MIT + Xray-core(MPL-2.0)。
详见 [`00-技术路线可行性.md`](00-技术路线可行性.md)（注意其 §4/§7/§9/§11 是**验证之前**的结论）。
